# Workflow

The reproducible [Snakemake](https://snakemake.readthedocs.io/) pipeline that turns
raw trade records into the network metrics and figures of the paper.

## Run it

From the project root:

```zsh
snakemake --sdm conda                 # full pipeline (builds conda envs on first run)
snakemake <rule> --sdm conda          # one rule
snakemake --sdm conda -n              # dry-run (list jobs, run nothing)
snakemake --sdm conda --cores 4       # parallel
```

There is no test suite: verify a rule by running it and inspecting `results/` plus
`workflow/logs/<rule>.log`. Only `get_uncomtrade` needs the `comtrade_apikey`
environment variable — the pre-seeded data in `resources/public/` lets every other
rule run without it.

## Pipeline shape

Three stages, run at **two aggregation levels** (`country_lvl` = every country;
`agg_eu` = EU members merged into one node, intra-EU flows dropped). Scope: FAO
divisions 01 Roundwood, 05 Sawnwood, 07 Wood-based panels, years 1996–2023.

```
Stage 1 (polars, sequential):
  correspondence_FAO_HS → get_uncomtrade → deflate_uncomtrade → join_fao_code → filter_data → aggregate_eu
                       wb_data ↗
Stage 2:  network_objects            (mirror_flows.csv + edge_lists.pkl)
Stage 3 (parallel):  one Python metric rule + one R plot rule per metric
```

Results land in `results/network_analysis/{agg_lvl}/` (git-ignored — regenerated by
the workflow). The rule dependency graph is rendered in [`../dag.pdf`](../dag.pdf).

## Contents

| Path | What it holds |
|------|---------------|
| [`Snakefile`](Snakefile) | Entry point: loads config + every rule file, defines the target `all`. |
| [`rules/`](rules/) | One `.smk` file per rule (inputs/outputs/params/conda). See [`rules/README.md`](rules/README.md). |
| [`scripts/`](scripts/) | The actual compute (`*.py`) and plotting (`*.R`) code. See [`scripts/README.md`](scripts/README.md). |
| [`envs/`](envs/) | Conda environment specs, one per tool stack. See [`envs/README.md`](envs/README.md). |

> Not tracked in git (created at run time): `logs/`, `benchmarks/`, and any
> `_sandbox/` scratch. These are safe to ignore or delete.
